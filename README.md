# Telegram-мониторинг чатов (папка «Батуми»)

Следит за всеми чатами из папки **«Батуми»** и присылает уведомление
(через бота — со звуком), когда кто-то ищет фотографа.

Работает **24/7 в облаке GitHub Actions** — ваш компьютер и Telegram
могут быть выключены.

## Как это работает

- GitHub каждые **5 минут** запускает новую «смену» мониторинга и
  автоматически останавливает предыдущую.
- Каждая смена подключается к Telegram, **добирает сообщения**, пропущенные
  за паузу, и дальше слушает чаты в реальном времени.
- Что уже обработано — хранится в `state.json`, поэтому уведомления
  не теряются и не дублируются.
- Файл сессии Telegram хранится **зашифрованным** (`session.enc`),
  ключ от него — в секрете `SESSION_KEY`.

## Правила поиска

Срабатывает, если в сообщении есть:

- слово **«фотографа»** само по себе, **или**
- корень **«фотограф»** вместе с одним из: *ищу, нужен, требуется, ищем,
  посовет, порекоменд*.

## Если что-то не работает

1. Откройте вкладку **Actions** — там видно каждый запуск.
2. Если запуски идут с ошибкой, GitHub пришлёт письмо.
3. Проверьте, что репозиторий не простаивал 60 дней: если расписание
   отключилось из-за неактивности, включите его в разделе **Actions →
   batumi-monitor → Enable workflow**.

## Остановить мониторинг

**Actions → batumi-monitor → Disable workflow** (или удалите репозиторий).

## Секреты

Все настройки (api_id, api_hash, токен бота, ключ сессии) лежат в
**Settings → Secrets and variables → Actions** и в файлах репозитория
не видны. В открытом виде в репозитории только код и `state.json`
(там лишь номера чатов и сообщений, без текста переписки).
